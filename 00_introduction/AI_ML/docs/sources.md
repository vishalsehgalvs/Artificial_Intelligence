Some upstream documentation links to deprecated features; the dated deprecation notice takes precedence. Optional code must be rechecked against the currently installed SDK and available model ID before use. A schema-valid output does _not_ establish that a model's decision is correct: evaluate accuracy, probability calibration, costs and failure cases independently. Avoid relying on third-party popularity counts or transient benchmark leaderboards as evidence.

## What changed for learners (checked 2026-09-28)

- **OpenAI Evals platform:** Think of this as an online test dashboard. OpenAI says existing evals become read-only on October 31, 2026, and the dashboard/API are scheduled to close on November 30. Do not start a new course project that depends on it. Our small, offline question-and-answer tests continue to work; for a hosted alternative, check the current [migration guide to Promptfoo](https://developers.openai.com/cookbook/examples/evaluation/moving-from-openai-evals-to-promptfoo) before signing up.
- **OpenAI Agent Builder:** The visual builder is scheduled to shut down November 30, 2026. Learn the _idea_ of tool permissions and agent loops first; for current OpenAI code follow the [Agents SDK guidance](https://developers.openai.com/api/docs/guides/agents). Do not confuse the builder with the Agents SDK.
- **Ollama:** The [quickstart](https://docs.ollama.com/quickstart) still separates models running on your own machine from models running in the cloud. A local app is not proof that your data stays local: check the selected model and network address. Its illustrated local download is about 7.2 GB, so it remains optional.
