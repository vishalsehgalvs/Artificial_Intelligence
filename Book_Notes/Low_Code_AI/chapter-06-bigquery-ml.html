Detailed Notes

Power plant objective and SQL data preparation

Source: book pp. 147-159 / PDF p. 163

Predict net hourly power output from weather/plant variables. Understand the row meaning, units, ranges, and prediction timing. Load CSV into cloud storage/BigQuery, verify schema and row counts, and clean malformed or missing values with explicit SQL.

Use SQL to profile distributions and identify outliers, then validate transformed data. Keep credentials and project identifiers out of shared notebooks. Track dataset versions and ensure train/evaluation rows are separated before model fitting.

Linear regression, features, correlation

Source: book pp. 160-174 / PDF p. 176

Regression predicts a continuous energy-output label. Inspect feature-label relationships and predictor-predictor correlations. Multicollinearity can destabilize coefficient estimates and make individual effects difficult to interpret even when overall predictions remain usable.

ŷ = β0 + Σ βjxj

Correlation is not causal influence. Use scatterplots and heat maps to generate hypotheses, not as the only feature-selection rule. Avoid leakage, keep transformations consistent, and compare errors on held-out data.

CREATE MODEL and explainability

Source: book pp. 175-182 / PDF p. 191

BigQuery ML expresses model training through SQL such as CREATE MODEL, specifying model type, label column, options, and a SELECT query. Separate training data from evaluation; retain model metadata and query versions for reproducibility.

Explainability tools can estimate how features contribute to predictions. Global importance and local attribution answer different questions and can be affected by correlated predictors. Explanations describe model behavior under a method; they do not prove physical causation. Use exercises to test edge cases and interpret the scale of predictions.

Neural networks and nonlinearity

Source: book pp. 183-192 / PDF p. 199

A neural network stacks learned affine transformations and activation functions. Nonlinear activations allow the network to model relationships that a single linear equation cannot. Without nonlinearities, stacked dense layers collapse into one linear transform.

h = φ(Wx+b)

Train a BigQuery ML DNN regressor using suitable features, loss, and evaluation. Compare with linear regression on the same holdout and metric. More flexibility can overfit and reduce interpretability; it does not imply a better result. The chapter’s Cloud Shell section illustrates inspecting cloud files and command output, rather than a new modeling method.
